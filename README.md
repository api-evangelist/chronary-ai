Chronary provides calendar infrastructure for AI agents, offering a REST API and MCP server to create calendars, schedule events, query availability, and integrate with human calendar apps. It includes free tier access, SDKs for multiple languages, and webhook notifications for real-time updates.

**Areas:** Calendar · Scheduling · AI Agents · API · Webhooks · Integration · Availability

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Chronary: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
